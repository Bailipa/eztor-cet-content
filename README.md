This repository contains the second original CET-4 mock examination published by EZTor. It is designed for learners, teachers, and builders who want a reproducible exam content pack instead of a locked PDF.

## What is included

- Structured paper data in JSON for importing into learning products
- Writing, listening, reading, and translation material
- Answer explanations and quality review notes
- Printable question and answer PDFs
- A generated listening track with a matching manifest

## Quick start

1. Start with [`content/cet4-original-002/README.md`](content/cet4-original-002/README.md).
2. Use `paper.json`, `written-material.json`, and `listening-script.json` to build your own practice experience.
3. Use the files under `output/` for classroom or self-study printouts.

## Why this format

The source of truth is structured content. PDFs and audio are delivery formats generated from that source, so a developer can build web, mobile, desktop, or LMS integrations without scraping a document.

## Content quality

The pack includes difficulty metrics, a difficulty review, and a quality review. Those files document the editorial checks applied to this release and make later revisions auditable.
