# EZTor CET4 原创模拟卷 002

> 一套开放、结构化、可复用的大学英语四级模拟内容包，包含试卷、答案解析、听力原文和合成音频。

[English](README.md) · 中文

[![内容类型](https://img.shields.io/badge/内容-CET--4-blue)](./content/cet4-original-002) [![许可证](https://img.shields.io/badge/许可证-GPL--3.0-green)](./LICENSE)

这是 EZTor 发布的第二套原创 CET-4 模拟卷。仓库面向学习者、教师和开发者，提供可直接阅读的练习材料，也提供适合导入学习产品的机器可读数据。

## 仓库内容

- 可导入学习产品的 JSON 题目数据
- 写作、听力、阅读和翻译材料
- 答案解析与质量评审记录
- 题目册和答案册 PDF
- 与听力原文对应的完整音频和 manifest

## 快速开始

1. 阅读 [`content/cet4-original-002/README.md`](content/cet4-original-002/README.md)。
2. 使用 `paper.json`、`written-material.json` 和 `listening-script.json` 构建自己的练习页面或题库。
3. 使用 `output/` 下的 PDF 和音频进行打印练习或课堂教学。

## 为什么采用这种格式

结构化数据是内容源，PDF 和音频是交付格式。这样可以在不解析 PDF 的情况下，把同一套内容接入网页、移动端、桌面端或 LMS。

## 质量记录

仓库包含难度指标、难度复核和质量复核文件，记录本次内容发布使用的检查结果，方便后续修订和复核。
